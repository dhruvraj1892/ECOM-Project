# 🛒 SMART-IKART

SMART-IKART is a full-stack e-commerce application that enables users to browse products, search by category, manage a shopping cart, and discover visually similar products using AI-powered image similarity search with vector embeddings.

## 🚀 Features

- Product browsing
- Product search
- Category filtering
- Shopping cart
- Order placement
- Responsive UI
- AI-powered image similarity search using PGVector

## 🛠️ Tech Stack

### Frontend
- React
- React Router
- Axios
- CSS

### Backend
- Spring Boot
- Spring Data JPA (JPA/Hibernate)
- PostgreSQL
- PGVector
- Docker

### AI / Similarity Search
- Image Embeddings
- PGVector for vector storage and nearest-neighbor similarity search

## 🗄️ Database

- PostgreSQL
- PGVector extension for storing and querying image embeddings
